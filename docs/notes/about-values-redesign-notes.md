# About Page Core Values Redesign Brief

The visual-edit target is the **Core Values** section in `client/src/pages/About.tsx`. The current treatment is a uniform six-card grid that gives equal visual weight to every value and does not create a memorable brand-story moment.

The redesign will replace that grid with a **Values Field**: a cinematic, image-led editorial composition that places the six principles in three purposeful pairs—innovation with excellence, integrity with people first, and sustainability with global collaboration. The new treatment will use a large visual focal point, more varied scale, restrained motion, and concise value descriptions so visitors can understand the relationship between SunEx’s principles at a glance.
